# microdocs

Своя вики: дерево страниц, текст в Markdown, хранение в S3.

- Требования — [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md)
- Что уже сделано и что нет — [docs/PROGRESS.md](docs/PROGRESS.md)
- Приложения для Android, Mac, iPhone и iPad — [docs/APPS.md](docs/APPS.md)

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`. Vite поднимается с `--host`, поэтому
приложение доступно и с телефона в той же сети — адрес печатается при старте.

Для работы с S3 нужен файл `.secrets/credentials` с профилем `microdocs`
(вне гита). Ключ читает только серверная часть, в браузер он не попадает.

```bash
npm test        # тесты
npm run build   # сборка
```

## Как устроено

```
shared/         типы, общие для клиента и сервера
src/domain/     операции над деревом, чистые функции
src/storage/    хранилища за одним интерфейсом PageStore:
                IndexedDB, сервер, и синхронизирующая обёртка над ними
src/state/      состояние базы, тело страницы, отложенное сохранение
src/components/ дерево, редактор, перенос страницы
src/serviceWorker/ офлайн-кеш интерфейса и вложений
server/api.ts   HTTP-контракт, о месте хранения не знает
server/storage/ порт BaseStorage и адаптеры к нему
android/        приложение для Android (WebView)
desktop/        приложение для Mac (Electron)
```

Серверное хранилище спрятано за портом `BaseStorage` в доменных терминах.
Сегодня за ним S3; чтобы перейти на Postgres, надо написать ещё один адаптер
и дописать ветку в `server/storage/index.ts` — HTTP-контракт и весь клиентский
код остаются как есть. Выбор задаётся переменной `MICRODOCS_BACKEND`.

Локальное хранилище — основное: чтение и правка работают без сети.
Записи уходят на сервер следом, неотправленное копится в очереди и уезжает,
когда связь появится.

Раскладка в бакете:

```
<baseId>/tree.json      структура: вложенность, порядок, заголовки
<baseId>/pages/<id>.md  тело страницы
<baseId>/assets/<путь>  вложения; в тексте — microdocs:asset/<путь>,
                        сервер отдаёт их по /api/assets/<путь>
```

Вложения пока кладут только импорты (`scripts/import-*.mjs`): загрузки файлов
из приложения нет. Без сети видны картинки, которые уже открывались.

Сам интерфейс без сети отдаёт service worker из кеша. Новая версия ставится
в фоне и включается кнопкой «Обновить» рядом со статусом синхронизации.

История версий — версионирование объектов S3, своего механизма нет.

## Боевой запуск

Сервер сам терминирует TLS и пускает только тех, чей клиентский сертификат подписан
доверенным центром. Nginx не нужен.

Проверить на своей машине:

```bash
npm run certs:dev          # учебный набор в .secrets/dev-certs/
npm run build              # клиент в dist/, сервер в dist-server/

MICRODOCS_TLS_KEY=.secrets/dev-certs/server.key \
MICRODOCS_TLS_CERT=.secrets/dev-certs/server.pem \
MICRODOCS_CLIENT_CA=.secrets/dev-certs/ca.pem \
PORT=8443 npm start
```

`client.p12` из `.secrets/dev-certs/` устанавливается в систему (пароль `microdocs`),
после чего браузер предложит его при заходе. Без сертификата соединение обрывается
на рукопожатии.

Это учебный набор, боевой сервер его не пустит. Где боевой сертификат —
в [docs/DEPLOY.md](docs/DEPLOY.md#клиентские-сертификаты).

**Владелец определяется по CN клиентского сертификата** — он же имя базы в хранилище.
В запросах база не называется, попросить чужую нельзя. Отсюда же берётся
мультитенантность: один сертификат — один человек — своя база.

Переменные: `MICRODOCS_TLS_KEY`, `MICRODOCS_TLS_CERT`, `MICRODOCS_CLIENT_CA`,
`PORT`, `MICRODOCS_STATIC`, `MICRODOCS_BACKEND`, `MICRODOCS_S3_BUCKET`.
При продлении серверного сертификата достаточно послать процессу `SIGHUP`.

В разработке TLS нет, поэтому владелец берётся из `MICRODOCS_DEV_BASE`
(по умолчанию `default`).

## Приложения

```bash
scripts/build-android.sh   # APK, нужны JDK и Android SDK
scripts/build-mac.sh       # DMG для Apple Silicon, только на macOS
git tag v0.2.0 && git push origin v0.2.0   # оба файла в GitHub Releases
```

Подробно — установка, ключ подписи APK, ограничения — в [docs/APPS.md](docs/APPS.md).

Иконки всех платформ и логотип собираются из одного знака: `npm run icons`
(`scripts/icons.mjs`). Картинки руками не правятся.

## Важно

**Dev-сервер (`npm run dev`) слушает всю локальную сеть и ничем не защищён.**
Это режим разработки; наружу выставляется только боевой запуск с mTLS.
